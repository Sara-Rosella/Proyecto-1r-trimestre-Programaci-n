# Proyecto-1r-trimestre-Programación

## ¿CÓMO SE PUEDE EJECUTAR EL PRROGRAMA EN TU ORDENADOR?

Para poder ejecutar el programa hay que descargar la carpeta 'ProyectoTrimestre1'.  
Luego hay que ejecutar el archivo en un programa que pueda ejecutar el lenguaje Java, nuestra recomendación es IntelliJ.

A partir de ahí, tienes que abrir IntelliJ o cualquier programa de tu elección y elegir la opción de 'abrir proyecto' en 'archivo' en la parte superior de la interfaz. Después tienes que seleccionar la carpeta descargada 'ProyectoTrimestre1' y de debería de abrir el proyecto.  

Por último es seleccionar el archivo 'ProyectoV3' y ejecutar el archivo dentro del programa elegido.  
  
  
  
## ¿CÓMO FUNCIONA LA APLICACIÓN?
La aplicación permite al usuario ejecutar el juego 'El templo del Dragón Heráldico Guiverno Blanco'  

El juego tiene un sistema de vidas, si te quedas con 0 vidas, la partida de termina.  

También tienes un inventario, al que puedes acceder siempre que no estés en medio de una prueba y puedes examinar o usar todos los objetos en el inventario.  

Consiste en explorar un templo, el cual está dividido en salas con pruebas, cofres y puertas.  

Dependiendo del camino que elijas, obtendrás diferentes recompensas, con el objetivo de obtener el tesoro del Dragón.
